# chatterbox
Believable chatbot of Good Janet using Markov chains and keywords. 

I made it using JavaScript that kind of emulated EMILY, in the way that she used to respond to you on those old computers. I also added in custom responses, so if you include certain words and/or phrases, it will spit out a specific answer. I liked finding out more about EMILY and the evolution of chatbots in order to become what they are now. I struggled with getting it phrased correctly in a way that would work with most anything you said back to it.
